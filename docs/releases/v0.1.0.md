# ModuQR v0.1.0 — First public release

**Release date:** 2026-11-06  
**Release line:** pre-1.0  
**License:** MIT

ModuQR v0.1.0 is the first public release of the static QR generator, designer and scanner. It focuses on reliable QR rendering and export, local-first privacy, and a professional browser-based workflow.

## Highlights

- **Ten payload types:** URL, text, email, phone, SMS, WhatsApp, WiFi, vCard, geolocation and iCalendar.
- **SVG-native design system:** custom module/finder styles, Connected and Fluid rendering, per-region styling, gradients, frames, logo cutouts and 60 searchable presets.
- **Scan safety:** deterministic risk analysis, real browser decode checks, degradation simulations and conservative Auto Fix.
- **Verified exports:** SVG, PNG, JPEG, WebP and PDF with preflight checks; raster output is checked again after encoding.
- **Local projects:** IndexedDB storage, tags, favorites, search, duplicate, revision history and versioned JSON import/export. Schema v1 and v2 documents migrate to schema v3.
- **Batch generation:** local CSV/TSV/JSON preparation in a Web Worker, templates, ZIP/PDF output, a 500-row ceiling and verified 500-entry SVG ZIP export.
- **Scanner and PWA:** camera/image scanner, Scan → Redesign, installable app and cached offline reuse.
- **Accessibility and responsive QA:** keyboard-friendly controls, RTL/touch behavior, axe-core smoke tests and desktop/mobile browser coverage.

## Privacy and security

Static QR payloads, WiFi credentials, uploaded logos, scanner images and saved projects remain in the browser. Static generation does not require a ModuQR application server. Imported designs, uploaded images and SVG logos are treated as untrusted input and validated before use. Scanned URLs are not opened automatically.

## Validation

The release workflow runs the complete acceptance gate from a clean checkout:

- Frozen pnpm install, lint, TypeScript, unit tests and production build.
- Production JavaScript bundle budget and high-severity production dependency audit.
- Managed Playwright matrix: Chromium, Firefox, WebKit, Mobile Chrome and Mobile WebKit.
- CodeQL static analysis.

The final pre-release browser run recorded **217 passed, 8 intentionally skipped and 0 flaky tests**. The full 500-row verified SVG ZIP acceptance test and offline service-worker smoke test each run once on desktop Chromium; their skips in the other browser projects are intentional.

## Install and run

**Requirements:** Node.js 22.14 or newer and pnpm 10.15.0 through Corepack.

```bash
corepack prepare pnpm@10.15.0 --activate
corepack pnpm install --frozen-lockfile
corepack pnpm dev
```

For production, set `NEXT_PUBLIC_SITE_URL` to the real HTTPS origin, then build and start the web app:

```bash
corepack pnpm install --frozen-lockfile
corepack pnpm build
corepack pnpm --filter @moduqr/web start
```

See [Deployment](../../docs/DEPLOYMENT.md) for security-header and service-worker deployment notes.

## Scope and compatibility

This is a **static web application release**. Dynamic redirects, hosted analytics, PostgreSQL, API keys, REST/OpenAPI and SDK/CLI/MCP packages are not included; they remain Phase 3 roadmap work.

ModuQR is pre-1.0. Public APIs and design schema compatibility may evolve before `1.0.0`; schema v1 and v2 import migration to schema v3 is included in this release. Roadmap phase numbers do not determine SemVer major versions.

## Downloads

The release includes a source archive and its SHA-256 checksum. Verify the archive before unpacking:

```bash
sha256sum --check moduqr-v0.1.0-source.tar.gz.sha256
```

On Windows PowerShell, compute the digest and compare it with the value in the `.sha256` file:

```powershell
Get-FileHash .\\moduqr-v0.1.0-source.tar.gz -Algorithm SHA256
```
