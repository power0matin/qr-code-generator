# Internationalization plan

English is the Phase 1 product language. The component layout avoids hard-coded physical alignment where practical, but full locale routing and translated UI are not claimed yet.

Phase 2 must add a real message catalog and verify Persian and Arabic with `dir="rtl"` at the document level, including editor controls, focus order, icons, numeric inputs and exported frame text. German, French, Spanish and Japanese follow the same message-key contract.
